How to Install via Home Assistant (HACS)Open your Home Assistant instance.Navigate to HACS (Home Assistant Community Store) in your sidebar.Click the three dots (⋮) in the top right-hand corner and select Custom repositories.Paste the URL of this GitLab repository into the Repository field.Set the Type dropdown menu to Integration.Click Add. The integration will appear in your HACS list.Click Download, choose the latest version, and restart your Home Assistant instance.How to ConfigureGo to Settings -> Devices & Services.Click + Add Integration in the bottom right corner.Search for Matrix Album Art Companion.Type in your MQTT Broker IP Address and click Submit. Your automations can now natively stream album art!
